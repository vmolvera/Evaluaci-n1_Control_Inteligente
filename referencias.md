## 13.2 Software y herramientas utilizadas

4. **Python Software Foundation.**  
   *Python Programming Language*.  
   Lenguaje utilizado para el desarrollo del sistema de procesamiento, entrenamiento neuronal, comunicación y control.

5. **NumPy Developers.**  
   *NumPy Documentation*.  
   Biblioteca utilizada para operaciones matriciales, procesamiento numérico e implementación de la Red Neuronal Artificial.

6. **Pandas Development Team.**  
   *Pandas Documentation*.  
   Biblioteca utilizada para lectura, organización y procesamiento de archivos CSV.

7. **SciPy Community.**  
   *SciPy Documentation*.  
   Biblioteca utilizada para procesamiento de señales, filtrado Savitzky-Golay y operaciones científicas.

8. **Matplotlib Development Team.**  
   *Matplotlib Documentation*.  
   Biblioteca utilizada para la generación y visualización de gráficas experimentales.

9. **Python Software Foundation.**  
   *Tkinter — Python Interface to Tcl/Tk*.  
   Herramienta utilizada para el desarrollo de la interfaz gráfica del sistema.
